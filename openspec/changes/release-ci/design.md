## Decisions

**D1. Smoke script, not pytest.** Plain Python with `assert`s and a non-zero exit on failure; no test dependencies beyond the package (pandas not required). It refuses to run if the parent of the `featranker` package directory (flat layout: the checkout root) contains a `pyproject.toml` naming featranker, i.e. it is not testing the installed copy. The expected version is passed in (`--expect-version`) and read from `pyproject.toml` by the workflow before leaving the checkout (`tomllib` in the release job; `sed` in the matrix job, whose Python 3.10 has no `tomllib`), so the check is not tautological. The console script must sit next to `sys.executable` (no PATH fallback). The run happens in a temporary working directory (catboost writes `catboost_info`), subprocesses have a 600 s timeout, and jobs have `timeout-minutes: 20`.

**D2. Virtualenv outside the checkout.** `python -m venv "$RUNNER_TEMP/venv"`, install `dist/*.whl` (with extras via `"$(ls dist/*.whl)[all,shap,plot]"`), `cd "$RUNNER_TEMP"`, run `python "$GITHUB_WORKSPACE/tests/smoke_installed.py" --expect-version "$version"`. Running a script by path puts its own directory on `sys.path`, so the script lives under `tests/` (no `featranker/` there) and the check in D1 guards the rest.

**D3. Matrix and pinning.** The wheel job has four cells: Python 3.10 with `scikit-learn>=1.5,<1.6` and Python 3.13 with the newest scikit-learn, each core-only and with `[all,shap,plot]`. 3.13 is used with extras because xgboost ships a pure-Python-tagged wheel, catboost publishes cp313 wheels and shap supports 3.13; the cell is untested here and is what CI exists to tell us (fall back to 3.12 if a wheel is missing). `tests.yml` has top-level `permissions: contents: read`.

**D3b. Pinning.** `release.yml` keeps SHA-pinned actions; `tests.yml` keeps its existing style.

**D4. Local check.** Verified locally (2026-10-24): the guard (`PYTHONPATH=. python tests/smoke_installed.py --expect-version 1.20.0` exits 1); a wheel built with `python -m build --wheel` from a copy of the repo in `$TMPDIR` (isolated build, network to PyPI); a venv without system site packages with only the wheel installed (numpy, scikit-learn, ... downloaded from PyPI) ran core-only with `--expect-version 1.20.0` and printed `SMOKE OK`; a venv with `--system-site-packages` (xgboost, catboost, shap, matplotlib) and the wheel installed `--no-deps --force-reinstall` ran with `--extras` and printed `SMOKE OK`. A wrong `--expect-version`, and a core-only run in the extras environment, both fail. The Python 3.10/3.13 cells and `[all,shap,plot]` installed from PyPI are only exercised in CI.
