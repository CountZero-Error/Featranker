## Decisions

**D1. families.** `FeatureRanker(families=None)`. Validated at construction: a dict with string keys and non-empty string values; any `collections.abc.Mapping` is accepted and copied to a dict; keys are checked against configured model names in `fit()` and, once before the split loop, in `rank_resampled()` (so `ConsensusSelector.fit()` raises `ValueError`, not "No split ranked successfully"). Built-in names exist only after `init_models`: the registry names of the chosen task and group, plus built-ins that failed to initialise, are accepted; any other name → `ValueError`. The model's report `family` and every vote use the mapped family. Old pickles load with `None`. `ConsensusSelector(families=None)` stores it as a parameter (clone/get_params work) and passes it to its rankers.

**D2. Constant within groups.** In `rank_features()` with `shuffle="within_groups"`, after `max_samples`, compute for each feature group whether every column has one distinct value (missing counted as a value) within every shuffle label. Report key `constant_within_groups`: sorted list of such group names (empty list when none) placed after `shuffle`. A `UserWarning` names them when non-empty. `rank_resampled` per-split reports carry it through `rank_features`, and a resampled report with `shuffle="within_groups"` has top-level `constant_within_groups`, the sorted union of the split lists (`[]` when none), placed after `shuffle`. Compare on the coded values used for scoring (categorical codes are fine).

**D3. Summary.** `summarize()` on a held-out or resampled report with a non-empty `constant_within_groups` adds one `warning` finding `constant_within_groups` with the list as evidence and a message saying their importance is zero by construction under within-group shuffling.

**D4. Docs only.** Weighted donor law (donors are the scored rows; "rows" permutes them regardless of weight, "within_groups" within a group, "circular" shifts; shadows are unweighted copies of every row), validation wording (k chosen inside the outer loop, nested CV), near-constant predictors not flagged, estimand text, custom-family risk, runnable ablation example (constructs its own ranker and report from a bundled dataset, actually run to produce the shown output).
